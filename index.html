Архитектура приложения и Live API Pipeline

Разделение слоев данных, предиктивный движок и внешняя интеграция рецептов

1. Persistence Layer (Storage)

Хранение нормализованных сущностей ProductItem и метрик EcoImpact в localStorage с отказоустойчивым парсингом.

2. Predictive Expiry Engine

Динамическая корректировка остатка дней: effectiveDays = Math.ceil(rawDays * storageFactor) для открытых и замороженных позиций.

3. External Recipe API (TheMealDB)

Двухэтапные HTTP-запросы (filter.php?i= и lookup.php?i=) с семантическим маппингом русских названий ингредиентов.

4. Eco-Impact Telemetry

Автоматический пересчет спасенной массы в сохраненный бюджет (₸) и предотвращенный углеродный след (2.5 кг CO₂/кг).
