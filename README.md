# Freshloop — Zero-Waste Kitchen & Smart Radar

Проект разработан для хакатона **NOTAR Academy Selection** по теме *Food Waste at Home*[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).

## Описание проекта
Веб-приложение для эффективного трекинга продуктов в домашних условиях, предотвращения их порчи и осознанного потребления. Интерфейс выполнен в премиальном продуктовом стиле с акцентом на эргономику и отсутствие «ишшного» дизайна.

## Ключевые особенности
- **Интерактивный радар свежести:** мгновенная оценка состояния холодильника.
- **Умный учет условий:** разделение продуктов по статусам хранения (в упаковке, открыто, в морозилке).
- **AI-рецепты спасения:** интеграция с TheMealDB API для поиска реальных блюд по ингредиентам из зоны риска.
- **Индикатор сэкономленных средств и веса спасенной еды.**

## Стек технологий
- Frontend: HTML5, CSS3 (Bento Grid, Custom CSS Variables, Inter font), Vanilla JS.
- API: TheMealDB REST API для подбора рецептов.
